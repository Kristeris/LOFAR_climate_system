Automated Data Collection

The Python sensor script runs automatically every 10 minutes via Spring Boot's scheduler, collecting temperature and humidity readings and broadcasting them via WebSocket to all connected clients.

⚡

Real-Time WebSocket Streaming

Built on STOMP over SockJS, every new sensor reading is instantly pushed to all connected browser clients — no polling, no delays. The entire frontend updates live.

🗄️

MySQL Persistence

All sensor readings are stored in a MySQL database via Spring Data JPA, enabling historical queries, trend analysis, and data export in CSV format.
