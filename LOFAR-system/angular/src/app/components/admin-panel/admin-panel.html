🛜 WebSocket Scheduler Control

Start or stop the backend scheduler that periodically runs the Python sensor script and broadcasts new readings to all connected clients via WebSocket.

Current state: {{ wsRunning() ? '▶ Running' : '⏹ Stopped' }}

🐍 Manual Sensor Trigger

Immediately run the Python sensor script outside the regular schedule and push the result to all connected WebSocket clients.

ℹ️ How It Works

  • Stop WebSocket — halts the scheduler so no new data is collected or broadcast. Existing data in the database is unaffected.
  • Start WebSocket — resumes the scheduler and reconnects the frontend WebSocket client.
  • Manual Trigger — runs the Python script immediately and broadcasts the result, regardless of scheduler state.
